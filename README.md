# 🚀 Getting Started

Want to run this portfolio locally?

 1️⃣ Clone the repository

```bash
git clone https://github.com/avinashverma39/portfolio.git
```

 2️⃣ Open the project

```bash
cd portfolio
```

 3️⃣ Run the website

Since this is a frontend portfolio, you can open:

```text
index.html
```

directly in your browser.

For development, you can also use the **VS Code Live Server extension**.
